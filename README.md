## 🏃 How to Run Locally

You can simply open `index.html` in any web browser, or serve it using any HTTP server:

### Option 1: Double-click to open
Double-click `index.html` to open it in your default browser.

### Option 2: Using Node `npx serve`
```bash
npx serve .
```

### Option 3: Using Python
```bash
python -m http.server 3000
```
Then visit `http://localhost:3000`.

## 🚀 Deployment

### Deploy to Vercel
1. Install Vercel CLI:
   ```bash
   npm i -g vercel
   ```
2. Run `vercel` inside this directory and follow the prompts.

### Deploy to GitHub Pages
1. Push this folder to a GitHub repository.
2. In the repository settings, go to **Pages** and select the `main` branch root (`/`).
